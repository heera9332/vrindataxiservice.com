# Project Rules & Guidelines

## Git & Commits
- **DO NOT commit changes automatically**: Never run `git commit` on your own in this project.
- Only make git commits when explicitly and directly requested by the user.
- Leave all modified or newly created files in the working directory so the user can review, test, stage, and commit them.

## Working Directories
- Do not modify files in `vrinda-taxi-server/` unless the user explicitly asks to touch that directory. Active development belongs in `vrinda-taxi/` and workspace root.
